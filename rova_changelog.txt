===== June 23, 2026 =====
- Synced with crDroid 12.11 sources (June security patches).

===== June 13, 2026 =====
- Synced with crDroid 12.10 sources (May security patches).
  Read official changelog:
  * https://crdroid.net/blog/2026-05-10-crDroid-12.10-is-here
- Upgraded kernel to 4.19.325-6.5-iusmac-cip128-st12-Mi8937v2-Mi8917
- Fixed dead deepsleep after using proximity sensor (e.g., on lockscreen, phone call)
- Implemented estimating charging current speed (in mA) on lockscreen for rolex
- Fixed charging driver on rolex not charging with charging current below 300mA
- Revamped "Smart Charging" feature (fixed padding, new slider, added USB 2.0/3.0 labels)
- Enabled additional charging current values (300/450/600/900/1300mA) in "Smart Charging"
- Fixed haptics "texture" soft ticks (e.g., when dragging slider thumb)
- Removed not-operational "Pick up" gesture & AOD tile from QS panel
- Added RAM+ option to adjust mode percentages in Settings > System
- Some minor fixes and improvements
- Updated translations

===== May 5, 2026 =====
- Synced with crDroid 12.9 sources (April security patches).
  Read official changelog:
  * https://crdroid.net/blog/2026-04-13-crDroid-12.9-is-now-available
- Upgraded kernel to 4.19.325-6.4-iusmac-cip128-st12-Mi8937v2-Mi8917
- Fixed dead deepsleep (affecting primarily rolex) when:
  1. Booting up with charger cable plugged in
  2. Unplugging the charger cable after fully charged (100%)
- Fixed fast battery % drop (100% => 80-90%) when unplugging the charger cable after fully charged (affecting primarily rolex)
- Fixed "phantom charger" (i.e., charging LED indicator stays on) after unplugging the charger (affecting primarily rolex)
- Fixed charging LED indicator randomly turn off and turn of on a moment later when fully charged (100%) and still plugged in (affecting primarily rolex)
- Fixed issue in current negotiation that led to longer charging times when using some "dumb" wall (AC) chargers
- Implemented torch light strength control on quick settings tile long press
- Implemented visual indicators (flashlight + notification LED blink + vibration) during kernel panic
- Bumped RevampedFMRadio app to v3.1.3-qcom
- Bumped KernelSU-NEXT to v3.2.0 (33129)
- Optimized overall performance
- Some minor fixes and improvements
- Updated translations
